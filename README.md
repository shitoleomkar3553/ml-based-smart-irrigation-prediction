# Smart Irrigation Prediction Using Machine Learning

A simple IoT / Edge ML project. A **Decision Tree** predicts whether irrigation is
required from three **simulated** sensor readings: soil moisture, temperature and humidity.
A Streamlit dashboard lets you enter readings (or generate simulated ones) and see the prediction.

> **Important:** the dataset is **synthetic**. It was generated in Python using transparent rules.
> It is NOT real field data, so the accuracy only shows how well the tree learned those rules.

## Folder structure
```
Smart-Irrigation/
├── train_model.py        # creates dataset, trains + evaluates + saves model
├── sensor_simulator.py   # simulated IoT sensor (new random readings each call)
├── app.py                # Streamlit dashboard
├── dataset.csv           # generated by train_model.py
├── irrigation_model.pkl  # generated by train_model.py
├── requirements.txt
├── README.md
└── SUBMISSION_MATERIALS.md   # report, demo script, viva Q&A, code explanation
```

## Setup on Windows + VS Code (PowerShell)

1. **Create and open the project folder**
   - Extract the ZIP (or create a folder named `Smart-Irrigation`).
   - Open VS Code -> *File* -> *Open Folder...* -> select `Smart-Irrigation`.
   - Open a terminal: *Terminal* -> *New Terminal* (it should be PowerShell).

2. **Check Python** (3.9 or newer)
   ```powershell
   python --version
   ```

3. **Create a virtual environment**
   ```powershell
   python -m venv venv
   ```

4. **Activate it**
   ```powershell
   .\venv\Scripts\Activate.ps1
   ```
   Your prompt should now start with `(venv)`.

5. **Install dependencies**
   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

6. **Train the model** (creates `dataset.csv` and `irrigation_model.pkl`)
   ```powershell
   python train_model.py
   ```

7. **(Optional) test the sensor simulator**
   ```powershell
   python sensor_simulator.py
   ```

8. **Launch the dashboard**
   ```powershell
   streamlit run app.py
   ```
   The browser opens at `http://localhost:8501`. Press `Ctrl + C` in the terminal to stop.

## How to use the dashboard
1. Move the three sliders, or click **Generate Simulated Sensor Readings**.
2. Click **Predict Irrigation**.
3. See the result, the recent predictions table, the model accuracy and the feature-importance chart.

## Pickle vs. a model registry
`pickle` only **saves and loads** the trained model (model persistence). It does **not** track
versions, metrics, or who trained what, which a full model registry does.
Only load pickle files you created yourself, because unpickling an unknown file can run malicious code.

**Optional extension (MLflow):** if your assignment requires formal model registration, install
MLflow (`pip install mlflow`) and, in `train_model.py`, wrap training with
`mlflow.start_run()`, log the accuracy using `mlflow.log_metric("accuracy", accuracy)` and
save the model with `mlflow.sklearn.log_model(model, "model")`. View runs with `mlflow ui`.
This is not included in the main project to keep it simple.

## Troubleshooting

| Problem | Fix |
|---|---|
| `ModuleNotFoundError: No module named 'streamlit'` (or pandas, sklearn...) | The environment is not active or packages are missing. Run `.\venv\Scripts\Activate.ps1`, then `pip install -r requirements.txt`. |
| `FileNotFoundError: irrigation_model.pkl` | Run `python train_model.py` first. (The dashboard also trains automatically if the file is missing, but only when started from inside the `Smart-Irrigation` folder.) |
| Packages are installed but VS Code still shows import errors | Wrong interpreter. Press `Ctrl+Shift+P` -> *Python: Select Interpreter* -> choose `.\venv\Scripts\python.exe`. |
| PowerShell: *"running scripts is disabled on this system"* when activating | Run `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`, answer `Y`, then activate again. Or use Command Prompt: `venv\Scripts\activate.bat`. |
| `streamlit` is not recognized | Activate the venv, or run `python -m streamlit run app.py`. |
| `python` is not recognized | Reinstall Python from python.org and tick **"Add Python to PATH"**, or try `py -m venv venv`. |
| Port 8501 already in use | `streamlit run app.py --server.port 8502` |
| Odd file-not-found errors | Make sure the terminal is inside the project folder: `cd path\to\Smart-Irrigation`. |
| Old model after changing code | Delete `irrigation_model.pkl` and `dataset.csv`, then run `python train_model.py` again. |
